# HS Solux — Site institucional

Site institucional estático da HS Solux, desenvolvido em HTML, CSS e JavaScript.

## Estrutura do projeto
- `index.html` — conteúdo e seções do site.
- `styles.css` — identidade visual e layout responsivo.
- `script.js` — menu mobile e atualização automática do ano no rodapé.
- `assets/hs-mark.svg` — símbolo vetorial da marca e favicon.

## Publicar com GitHub Pages
1. Abra **Settings** neste repositório.
2. Acesse **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch **main** e a pasta **/(root)**.
5. Clique em **Save** e aguarde a publicação.
6. O GitHub exibirá o endereço público do site na própria tela do Pages.

## Observações
- O site é estático; não possui backend nem formulário que armazene ou envie dados.
- Os botões de contato abrem o e-mail ou o WhatsApp.
- A mudança para HS Solux altera a identidade pública do site; não altera os identificadores, códigos ou configurações internas dos aplicativos.
- O endereço do repositório e do GitHub Pages permanece o mesmo até que seja feita uma alteração separada.
- Antes de divulgar, confira se os status exibidos para os aplicativos continuam corretos.

# HS Solux — site institucional

Site institucional estático da HS Solux, publicado no GitHub Pages com domínio próprio.

## Endereço público

- https://hssolux.com.br/

## Estrutura

- `index.html` — conteúdo, metadados sociais, SEO e dados estruturados.
- `styles.css` — identidade visual, layout responsivo e acessibilidade.
- `script.js` — menu móvel acessível e atualização do ano no rodapé.
- `assets/hs-mark.svg` — símbolo vetorial oficial da marca.
- `assets/hs-social.png` — imagem para compartilhamento em redes sociais.
- `robots.txt` e `sitemap.xml` — orientação para mecanismos de busca.
- `CNAME` — domínio personalizado usado pelo GitHub Pages.
- `DECISIONS.md` — histórico de decisões duráveis do site.

## Publicação

O GitHub Pages publica a branch `main` a partir da raiz do repositório. Alterações nessa branch podem atualizar automaticamente o site público.

Antes de publicar:

1. Confira a navegação por teclado e o menu móvel.
2. Teste as larguras de 320, 375, 768 e 1440 pixels.
3. Valide links, HTML, metadados e arquivos de indexação.
4. Confirme que nenhuma solução é apresentada como disponível antes do lançamento.

## Observações

- O site não possui backend, formulário, cookies ou armazenamento de dados.
- O contato abre o aplicativo de e-mail do visitante.
- Informações sobre produtos devem ser publicadas somente após confirmação de nome, escopo e disponibilidade.
